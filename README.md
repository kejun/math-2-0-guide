# Math 2.0 · 27 页中文解读

原稿：https://teorth.github.io/tao-web/slides/math-2-0-caltech-2026.pdf

包含原图对照、27 页中文解读、来源链接、目录、搜索、页码跳转，以及依据原稿第 18、19、21 页重绘的交互研究生态图。

## 构建

无需安装前端依赖。直接用静态服务器提供本目录，或以 GitHub Pages 的 `main` 分支根目录发布。

编辑 `content.json` 后运行 `python build.py` 生成 `index.html`。样式与交互分别位于 `style.css` 和 `app.js`。

原图 `slide-01.webp` 至 `slide-27.webp` 从 2026-10-11 读取的原 PDF 渲染，用于逐页对照。
